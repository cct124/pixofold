## 目标与验收

1. 延用固定 MozJPEG 字节 helper、受控进程与可靠输出，增加普通8-bit灰度/RGB/YCbCr有损；明确质量映射、实际处理/回退报告，100仍为有损模式。
2. 保留颜色解释、分量/采样、基线/渐进类别、方向和支持的元数据。ICC、四分量颜色、嵌入缩略图或不明确颜色语义只在现有无损验证支持时回退；复杂Exif/未知APP/APP11继续拒绝，不复用PNG移除许可。
3. 源/候选完整解码，保持尺寸/颜色/元数据；落盘候选与内存候选绑定，拒绝另一合法JPEG替换。只有更小且通过验证的候选能提交，无收益不产生备份/副本。
4. 实际执行复查系数/解码工作集、尺寸与扫描上限；覆盖损坏、超限、取消、超时、源变化、候选破坏、冲突及三种输出策略。资源准入共用模型留待第二段。
5. 真实有损回归接入已有 jpeg:core:check 与三平台 JPEG job；保留PNG/无损回归、统一检查及正式构建。自生成语料的观感/误差记录不扩大为真实照片或ICC色彩校准。

## 阶段边界

- 本阶段交付为 J1b 第一段；批次共用模型/总资源预约属于第二段，产品JPEG入口/缩略图/随包部署属于J2，继续按验收门槛推进。
