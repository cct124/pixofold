# PixoFold HTML 交互原型

入口：[PixoFold.html](PixoFold.html)。直接用浏览器打开，无需安装依赖、构建或启动正式应用工程。以 [亮色设计图](PixoFold-亮色.png) 为主要视觉依据，并使用新绘制的 [SVG logo](logo/PixoFold-logo.svg)。

这是供后续反复修改的界面与交互参考。**压缩进度、结果大小和减少比例均为演示数据，不会真正压缩、上传、覆盖或输出文件。** 支持实际拖入或选择图片与文件夹，识别后自动开始模拟，交互参考 png-palettes 的导入即处理流程。

**2026-09-24产品规则更新：正式工作台启动后不再提供主动取消功能。** 本文下方及HTML中的取消按钮/模拟取消流程保留为历史演示，不再是正式产品验收要求；当前以[UI交互设计](../架构设计文档/ui-interaction-design.md)为准。原生选择框取消、未启动清单清除以及应用关闭时的安全收尾不受影响。

## 文件与运行

HTML 内包含全部 CSS、JavaScript 和通用 SVG 图标。保持以下相对位置即可离线打开：

```text
UI界面设计/
  PixoFold.html
  PixoFold-亮色.png          可选演示文件的缩略图来源
  logo/
    PixoFold-logo.svg        标题栏、关于与浏览器图标
```

首次打开默认亮色、有损模式、高档 80、原图覆盖，中央显示空的导入识别区。导入后自动切换为图片列表并启动模拟，不需要手动开始；需要示例时可选择「关于 → 导入示例并模拟」。设置会保存在浏览器的 localStorage 中；修改 HTML 的默认值后，可通过「关于 → 重置设置」查看新的初始状态。

刷新页面保留主题、语言、质量、输出模式、副本输出目录及高级设置，中央恢复空状态，不持久化导入文件或演示进度。文件元信息与本机缩略图 URL 只保存在当前页面；缩略图延迟加载，清除、新批次导入和关闭时释放 URL。旧配置未包含输出模式或模式无效时，回退为原图覆盖，已保存的副本目录仍保留。浏览器禁止存储时也可使用当前页面。

## 已实现的交互

| 区域 | 行为 |
| --- | --- |
| 导入区 | 多文件选择、目录选择、拖拽文件与目录；递归读取子目录、保留相对路径；按路径、大小和修改时间在本次导入内去重；识别完成即自动模拟 |
| 图片列表 | 空闲时隐藏，导入后替换中央引导区；显示所有已识别图片的缩略图、文件名/相对路径、原始大小、模拟结果大小、减少比例和状态；当前处理行突出显示并附单文件进度；完成后保留全部结果 |
| 底部提示与汇总 | 桌面端至少约 170 CSS px，固定在工作区下方。无有效图片时显示批量导入、参数设置和快捷操作技巧，隐藏统计与进度；有图片时显示总文件数、原始总体积、当前模拟总体积、累计节省空间/比例、各状态数量、总进度条及取消/重试/下一批/清除操作；列表独立滚动 |
| 质量 | 0–100 连续滑块，按整数逐值调整，无档位圆点和轨道下方标签；当前质量描述以纯文字显示在「压缩质量」标题行右侧，无边框和背景；方向键每次加减 1，Home/End 到达 0/100 |
| 精细输入 | 允许 0–100 整数；输入 76 时滑块移动到 76%，描述为「高」；参数无效时保留已导入文件并等待修正，恢复有效后自动开始；Escape 恢复上次有效值 |
| 模式 | 有损/无损切换；无损禁用质量控件，切回有损恢复原质量；无损批次快照不含有损质量参数 |
| 输出 | 与压缩设置使用相同的分段切换样式：「原图覆盖 / 另存副本」，默认原图覆盖；仅另存副本时展示现有输出目录控件，可以填写路径或使用只读目录选择；切换时保留副本目录，不执行文件写入 |
| 高级选项 | 折叠/展开、速度、抖动强度及校验、保留元数据；保留目录结构和同名处理仅在另存副本时展示并生效 |
| 任务流程 | 每次导入替换上次图片列表及汇总并自动启动；处理过程中暂不接收新批次；取消后保持结果，可重试未完成文件；启动时固定参数快照，运行中修改设置只影响后续启动的批次 |
| 演示场景 | 「关于 → 演示场景」可切换全部完成，或包含失败与无收益；「导入示例并模拟」直接启动四个示例文件；失败项可通过底部的重试入口演示重试成功 |
| 辅助操作 | 浅色/深色仅显示太阳/月亮图标，保留选中态、随语言切换的悬停提示与无障碍标签，窄窗口仍显示图标；支持中文/英文、关于、恢复默认设置；标题栏最小化/关闭为页面内模拟，最大化按钮切换浏览器全屏 |
| 滚动区域 | 图片列表、导入区与设置栏预留固定滚动条空间，底部汇总不随列表滚动；Edge/Chrome 使用 6px 透明轨道、低不透明度圆角滑块并隐藏上下箭头，其他浏览器采用细滚动条回退样式 |

文件识别检查 PNG/JPEG/GIF 签名和 PNG 头部的 APNG 标记（最多读取前 64 KiB）；这里的基本识别不代替正式后端对图片、颜色、动画帧和输出文件的完整验证。空文件、非支持格式、重复项和读取失败会统计反馈；空目录或没有支持图片时不会启动模拟。

浏览器目录能力不一致：输入目录采用文件夹选择或拖拽遍历；输出目录在支持时调用只读目录选择，否则允许填写名称或路径。无论选择方式如何，本原型都不会提交写入操作。

目录拖放优先使用浏览器提供的 FileSystemEntry 接口，持续读取目录分页并递归访问子目录；普通文件可回退到 DataTransfer.files。目录拖放不可用时，可用「选择目录」导入。完成后可在底部选择文件/目录或继续拖入下一批，新的导入只对本批去重，因此可重复导入同一文件验证不同设置。

底部视图依据列表是否包含有效图片切换，不依据是否正在压缩切换：参数待修正、处理中、完成或取消后均显示汇总，清除结果后恢复操作技巧。仅导入不支持的文件时，保留技巧并显示识别结果；扫描时保留扫描状态反馈。两种视图共用底部容器，桌面端保持相同高度，窄屏随文字与操作换行适应高度。

汇总的「当前总体积」把成功完成项替换为模拟输出大小，待处理、处理中、失败、取消、无收益项仍计原始大小；节省量只累计成功项，不提前估计。总进度按本批全部文件等权计算：完成/失败/无收益项计 100%，当前项计其进度，待处理计 0；取消保留中断位置。重试时已完成项保持结果，仅失败/取消项重新从 0 开始，因此总进度可能下降后再次增长。100% 表示本轮已处理完，不代表全部成功，具体结果看状态计数。

真实文件使用浏览器本机缩略图，损坏或无法解码时回退图标；演示缩略图取自原设计图。列表不会展示实际压缩后的像素对比，因为原型没有编码器。窄屏将列表行改为卡片排列，保留全部字段；桌面长列表只滚动中间区域，进度更新不重建整张表或改变滚动位置。

## 修改入口

在 HTML 内按编号注释定位，不需要跨文件寻找主要逻辑：

| 注释分区 / 名称 | 适合修改的内容 |
| --- | --- |
| `01. 设计变量` | 亮暗色值、主色、边框、圆角、标题栏高度、内边距、字体 |
| `02–05` CSS 分区 | 双栏比例、识别区、图片列表、固定底部汇总、侧栏、弹窗、窄窗口布局 |
| `<main>` 与 `<dialog>` | 页面结构、控件顺序、弹窗内容 |
| `06. 原型配置与文案` | `QUALITY_THRESHOLDS`（描述区间）、`DEFAULTS`、中英文 `TEXT`、四个示例文件 |
| `07. 设置状态与界面渲染` | 档位归属、有效值与输入草稿、自动启动条件、列表行增量更新、总体积与总进度计算 |
| `08. 本地文件导入` | 文件签名、目录递归与分页、读取错误、批次内去重与识别统计 |
| `09. 可替换的演示处理器` | `DemoProcessor` 的演示耗时、成功/失败/无收益场景；`batchSettings()` 的参数快照 |
| `10–11` JS 分区 | 清除结果、取消/重试、弹窗、快捷键、文件选择与拖放事件 |

浏览器开发者工具可执行 `PixoFoldPrototype.getState()` 查看设置、任务和批次快照的副本。界面不会直接修改返回对象。

输出模式保存在 `settings.outputMode` 中，取值为 `overwrite` 或 `copy`；`settings.output` 单独记忆副本目录。批次快照的 `output` 使用 `{ kind: 'overwrite' }` 或 `{ kind: 'copy', directory, keepStructure, conflict }`，原图覆盖不会携带隐藏的副本目录选项。运行中切换输出模式只影响下一批任务。

## 后续正式工程的使用方式

- 将本 HTML 作为经过确认的交互与样式参考，逐步拆分为导入识别区、图片列表、固定汇总栏、质量控件、设置及对话框组件；正式大列表按需要引入虚拟化。
- 继续使用统一质量数值、派生档位和批次快照规则；类型、存储和后端职责参照 [UI 交互与质量映射设计](../架构设计文档/ui-interaction-design.md)。
- 用真实 Rust 任务事件替换 `DemoProcessor`，移除演示场景、示例结果与原型标记；结果大小和百分比必须来自实际任务。
- 文件对话框、路径、目录权限、输出提交和窗口操作由正式桌面 API 接管；浏览器相对路径不能代替正式后端文件路径和授权。

## 本轮验证

本轮已在本机 Edge 无头浏览器中检查空状态与列表切换、全部图片行、真实缩略图、逐文件大小与减少比例、混合成功/失败/无收益结果、实时总体积和节省量、整批总进度，以及取消和重试。另用 24 个真实文件验证长列表独立滚动、底部汇总可见和位置稳定、进度更新不重置滚动位置、文件名文本显示及缩略图 URL 释放。

文件拖入使用浏览器 DataTransfer 验证；目录拖入使用 FileSystemEntry 接口桩验证递归、分页、混合文件回退、读取失败和空目录，并检查文件名按文本显示。系统文件管理器到浏览器的实际拖放仍取决于浏览器提供的目录接口。

已检查真实嵌套目录导入、非法质量等待与修正后自动启动、下一批文件拖入、资源替换、无支持文件/空状态、运行中修改质量和输出模式不改变本批快照、中英/亮暗切换、清除与刷新恢复，以及 1586/1080/390 像素宽度布局；亮暗主题与窄窗口另做截图检查。此前完成的连续质量和输出切换规则保持不变。

补充检查空状态技巧与汇总切换、完成/取消后保留汇总、清除后恢复技巧、无支持文件反馈和非法参数等待。1586 像素窗口下空闲、处理中、完成及清除后的底部高度均为 170 CSS px，位置一致；1080/390 像素窗口、中英文本及亮暗主题显示正常，无横向溢出。

浏览器检查未发现脚本异常或外部网络请求；真实输入测试文件在模拟前后的哈希保持一致。真实压缩、原生桌面窗口行为和后端文件输出不属于本原型的验证范围。
